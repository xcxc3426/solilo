# Materials and provenance

## Original ASCII assets

The room glyph grids, voice portraits, authored dialogue, code, documentation and renderer were created for SOLILO. Source ASCII grids are supplied as plain text and in the room atlas. Terminal frames are exports of the included renderer, using those exact source assets and scripted dialogue.

## Header artwork

`assets/brand/solilo-header.png` was generated with the built-in image-generation tool from the project-specific prompt in `assets/brand/PROMPT.md`. It is editorial artwork; the room protocol stores canonical ASCII glyphs, not this PNG.

To the extent the contributor has rights in that generated artwork, permission is granted to use, modify and redistribute it with attribution to SOLILO / Ashley Tooligan and preservation of this provenance note. This does not assert exclusive copyright over machine-generated imagery or trademark clearance.

## Font

The terminal renderer uses bundled DejaVu Sans Mono. Its original license is supplied in `assets/fonts/LICENSE.txt`. This font belongs to its respective authors and is not represented as original SOLILO artwork.

## Platform references

Solana documentation is cited by link in the source notes. No third-party program code, official logos, private data or copied project interface is bundled. Solana is the target network, not a claimed sponsor.
