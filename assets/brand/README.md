# SOLILO identity

The primary header is `solilo-header.png`: two fragmented machine faces, a doorway, and the SOLILO wordmark. The application wordmark is text so it remains clear at terminal scale.

The world is almost entirely black, ash and warm grey. Muted lilac distinguishes traces and a small mint accent distinguishes a selected record. Bright colors should not overwhelm the ASCII scene.

Keep the room representation separate from the editorial header. The protocol carries printable glyph bytes that can be rendered by an independent client.
