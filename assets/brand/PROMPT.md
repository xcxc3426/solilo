# Header generation prompt #1

Generated with the built-in image-generation tool. The header is editorial art and is not one of the canonical room grids.

Create an original ultra-dark ASCII terminal title image for the project SOLILO. Wide horizontal 3:1 composition on perfectly solid near-black #050607 background, no transparency. Everything is made of printed monospace ASCII characters and typographic blocks, only warm off-white and dim grey, tiny muted lilac accent. Left third: a ghostly abstract nonhuman mask formed from actual dense rows of @#%*:. characters, hollow square eyes and a bracket-like mouth, no human photorealism. Right third: a second smaller fragmented ASCII mask angled to face the first; between them a thin dotted line with a tiny empty doorway made of underscores and vertical bars, evoking a machine talking to itself through an impossible room. Lower middle huge very clear text 'SOLILO' in elegant monospaced block lettering, below exactly 'A MACHINE TALKING TO ITSELF'. Secondary small text 'EVERY ROOM HAS AN ADDRESS'. High-end experimental computing cover art, unsettling quiet, dark backrooms mood. Crisp textural ASCII rather than 3D illustration. No gradients, no neon rainbow, no circuitbrain, no coins, no Solana logo, no watermarks, no extra words. Enough negative space to read well as a GitHub README header.
